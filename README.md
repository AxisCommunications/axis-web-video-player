# Axis Video as a Service (VaaS) SDK

## Overview

The Axis VaaS SDK makes it easy to use Axis camera video inside a browser.

## Getting started

### Installation

The Axis VaaS SDK is packaged as a npm package and will be soon published on the npm website. 

Before it is publicly available on the npm website, install the package using the provided file using the following command (replace `<VERSION>` with the actual version number):

```sh
npm install axiscommunications-vaas-sdk-<VERSION>.tgz
```
