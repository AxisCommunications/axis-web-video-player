## Reporting bugs
We use GitHub issues to track bugs and errors. If you run into an issue with the project:

- Open an [issue][issues_new].
- Explain the behavior you would expect and the actual behavior.
- Please provide as much context as possible and describe the *reproduction steps* that someone else can follow to recreate the issue on their own.

## Contributing code
Before opening a Pull Request (PR), please consider the following guidelines:

- Please make sure that the code builds on your local system.
- The PR will have to meet the code standard already available in the repository.

When you are satisfied with your changes, open a new PR.

[issues_new]: https://github.com/AxisCommunications/axis-web-video-player/issues/new
